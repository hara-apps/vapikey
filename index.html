Variational: прокси и ключ

Ключ API даёт модулю право торговать на вашем счёте Variational: открывать и закрывать позиции. Выводить средства через API сейчас нельзя, но площадка может добавить такую возможность без предупреждения. Поэтому используйте отдельный кошелёк только под этот модуль и держите на нём столько, сколько готовы потерять. Торговля идёт с плечом, возможны убытки вплоть до ликвидации. Вводите приватный ключ (seed), а не публичный — по виду их не отличить. После ввода ключ хранится в зашифрованном виде и больше нигде не показывается.

Только HTTP-прокси: SOCKS модуль не применяет. Страна выхода проверяется по правилам Variational, один выходной IP — один человек.

Прокси проверяется до сохранения: при ошибке он не сохраняется. Видно будет только хост и порт.
Ключ проверяется на площадке до сохранения: при ошибке он не сохраняется.
